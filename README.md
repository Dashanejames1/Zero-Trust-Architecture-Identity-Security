## 🔬 Tasks / Assessments Performed

### 1. Verify the Zero Trust principles: verify explilicitly, least privilege, assume breach

Verify Explicitly — Never assume a user or device is trustworthy based on location alone. Every access request must be authenticated and authorized using all available data points: identity, device health, location, service requested, and behavior. Being inside the corporate network is no longer enough.

Least Privilege — Users, services, and systems get only the permissions they need for a specific task, and nothing more. Access is time-limited where possible. This limits the blast radius if credentials are compromised.

Assume Breach — Design the environment as if an attacker is already inside. Segment everything, encrypt traffic internally, log all access, and minimize the trust between systems so one compromised component can’t reach everything else.

### 2. Explain Micro-segmentation and how it limits lateral movement.

# Output

Traditional networks are flat — once an attacker gets in, they can move freely between systems. Micro-segmentation breaks the network into isolated zones with strict access controls between each segment.

In practice: if an attacker compromises a workstation in the HR VLAN, micro-segmentation prevents them from pivoting to the finance VLAN or the domain controller. Each segment requires separate authentication and authorization to reach the next. This directly addresses the kill chain step between initial access and impact.

Exam tip: “Which architecture best prevents lateral movement?” → Zero Trust with micro-segmentation. This appears across multiple CySA+ domains.

### 3. Researching MFA Types: TOTP, hardware keys, push notification, SMS (weakest)


MFA Type	How It Works	Strength

Hardware Security Key (FIDO2/YubiKey)	Physical key plugged in or tapped — cryptographically bound to the site	Strongest — resistant to phishing

TOTP (Authenticator App)	Time-based one-time password generated by an app (Google Authenticator, Authy)	Strong — but codes can be phished in real time

Push Notification	App sends an approval prompt to your phone	Moderate — vulnerable to MFA fatigue attacks (attacker spams prompts until user approves)

SMS / Text Code	One-time code sent via text message	Weakest — vulnerable to SIM swapping and SS7 interception

Exam tip: SMS is always the weakest MFA option. Hardware keys are always the strongest

### 4. Explaining PAM (Privileged Access Management) and why it matters for insider threat.

PAM controls, monitors, and audits access for privileged accounts — admins, service accounts, root users, and anyone with elevated permissions.

Why it matters for insider threat: Most insider threat scenarios involve an employee or contractor abusing legitimate elevated access. PAM addresses this by enforcing just-in-time access (privilege is granted only when needed and expires automatically), recording privileged sessions so every action can be reviewed, requiring re-authentication for sensitive operations, and alerting on unusual privileged behavior.

Without PAM, a disgruntled sysadmin with standing admin rights can exfiltrate data or destroy systems with nothing to stop them in real time.

### 5. Practice Scenario : What control would have prevented this lateral movement.

If the attacker moved between network segments → micro-segmentation would have contained them to the initial compromise zone.

If the attacker reused credentials across systems → least privilege + PAM would have limited what those credentials could reach.

If the attacker bypassed MFA or used a stolen session → hardware MFA (FIDO2) is phishing-resistant and would have blocked the initial login.

If the attacker exploited implicit trust between internal systems → verify explicitly — mutual authentication between services (mTLS, service accounts with scoped tokens) closes that gap.

General rule: For any lateral movement scenario on the exam, the answer is Zero Trust + micro-segmentation unless a more specific control is described.

## 🔑 Key Takeaways

The three principles are the lens: verify explicitly, least privilege, assume breach. Most Zero Trust exam questions reduce to one of these.

Micro-segmentation is the default answer for lateral movement unless the scenario names a more specific control.

MFA strength order is a reliable memorization point: hardware key > TOTP > push > SMS.

PAM is the insider-threat control — standing admin rights are the risk; just-in-time access and session recording are the answer.
